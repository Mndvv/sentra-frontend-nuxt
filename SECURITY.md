# Security Policy

## Supported Versions

We take security seriously and patch vulnerabilities in the following active versions of our project:

| Version | Supported          | Notes |
| ------- | ------------------ | ----- |
| 1.x     | :white_check_mark: | Currently active development and maintenance. |
| < 1.0   | :x:                | Legacy versions are no longer supported. |

## Reporting a Vulnerability

If you discover a security vulnerability within Sentra Frontend, please **DO NOT** create a public issue. Instead, please privately report it to our Security Response Team.

1. Email your findings to **security@sentracore.invalid**.
2. Include steps to reproduce the vulnerability, along with any relevant proof-of-concept code.
3. We will acknowledge receipt of your vulnerability report within 24-48 hours.

Our security team will investigate the issue and work with you to resolve it in a timely manner. We will notify you when the issue has been patched and before a public disclosure is made.

### Bounties

At this time, we do not operate a formal bug bounty program, but we deeply appreciate the efforts of security researchers who help keep our ecosystem safe. Notable contributors may be acknowledged in our security advisories.
